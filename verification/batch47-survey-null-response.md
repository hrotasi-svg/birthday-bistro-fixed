# 第47批次登入會員 error 修復驗證

## 根因

體驗調查表的 `getExperienceSurveyForMember()` 在會員尚未提交問卷時回傳 `undefined`。tRPC 查詢程序不能把 `undefined` 作為正常資料回傳，前台因而將「尚無問卷」的正常狀態判定為 query error，造成登入會員後左下角出現 error。

## 修正

未連線、驗證失敗或查無問卷的情況，現在一致回傳 `null`；前台既有 `existingExperienceSurvey ? … : …` 條件可正確顯示「體驗調查表」入口，不會視為錯誤。已透過不含真實會員資料的 tRPC 查詢驗證回應為 `{"result":{"data":{"json":null}}}`。

問卷提交後的感謝訊息固定分為下列三行：

1. 感謝您參與本次 壽星餐酒館 活動！
2. 您的每一份回饋，
3. 都是我們持續進步的重要力量。

## 回歸結果

TypeScript 檢查、15 個測試檔共 52 項測試與正式建置均通過；體驗調查表來源測試亦保護空資料 `null` 契約及三行文字。
