# 第48批次了解更多金屬漸層框驗證

## 根因與修正範圍

了解更多頁清單按鈕的 hover 使用 `border-amber-500`，返回主功能按鈕使用 `border-amber-400`。全域第39批次規則會將任何黃色系互動框覆寫為粉色，因而顯示粉色框。

僅在 `MorePage.tsx` 定義 `metallicFrameStyle`，以透明 2px 邊框及雙層背景建立金屬漸層外框，內層維持深色。兩類按鈕已移除會觸發全域粉色覆寫的 amber class；文字、尺寸、位置、六個了解更多項目與返回主功能導航均保留。

## 實際驗證

手機 375×812 與桌面 1280×720 截圖均確認六個清單框與返回主功能按鈕呈現多段金屬金色漸層，未見粉色框。54 項 Vitest、TypeScript 檢查與正式建置均通過；更新後近期主控台無例外，網路日誌無 4xx／5xx 請求。
