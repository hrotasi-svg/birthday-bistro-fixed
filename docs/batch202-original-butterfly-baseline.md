# 第202批次：原來蝴蝶基準回復與指定細節

使用者明確表示第201批次的蝴蝶外形不可接受，要求以原來蝴蝶版本為基準重作。本批次已自第197批次擷取四片花瓣翼、水平身體與頭部輪廓作為回復基準；不修改門店選擇頁以外的任何設定。

開發預覽已重新載入門店選擇頁。後續驗收固定在既有外飛、轉向、回程與融合時序中檢查四翼外觀、翼根中心身體與雙觸鬚、相對翼面±60度同步拍翅、以及從翼後錨點沿剛飛過路線緩慢下落的金粉。

外飛中段實機量測顯示四片翼與兩根觸鬚均已存在。身體中心約為 x=664.06、y=953.58，翼後尾端錨點約為 x=651.48、y=951.82；最新金粉位於約 x=651.13、y=952.66，緊接於翼後，較早批次沿剛飛過的外飛弧線獨立下落。

提高翼後金粉的亮度與微小光暈後，開發預覽已重新載入；門店選擇頁原背景、Logo、原火焰、文字、分店按鈕與其他位置均維持不變。

外飛中段固定影格時，最新金粉約 x=650.70、y=953.18，緊接翼後錨點約 x=651.48、y=951.82。恢復連續飛行約0.92秒後，量測到多批動態金粉同時保留於 x=636.91/y=1017.26、x=612.91/y=1050.80、x=548.43/y=1074.14 等已飛過的位置，而當下翼後錨點已移至 x=358.93/y=1078.18；金粉會從尾端陸續出現，再獨立向下緩慢下落。

390×844手機尺寸驗收確認門店選擇頁背景、Logo、火焰、文案、分店入口與返回首頁位置均維持原有版面；蝴蝶循環只在既有火焰階段出現，未改動其他頁面設定。
