# 第182批次：拍翼飛行與下落金色細粉

> 本批次只修正第181批次蝴蝶本體與光點。所有既有火焰、圓形光源、光環、側光暈、煙霧、外層餘暉、Logo、文字、頁面功能、短按六色與520ms長按均鎖定不變。

## 已發現差異與修正原則

| 項目     | 上一版問題                                                     | 本次限定修正                                                                                           |
| -------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 蝴蝶飛行 | 翼與身體被同一主體視覺包覆，拍翼辨識度不足，飛行弧線不夠明確。 | 將蝴蝶本體縮成獨立中心身體，左右翼分別使用不同拍翼節奏，主體在容器內先往左下飛出，再以大弧度回到原點。 |
| 金色效果 | 8點放在蝴蝶本體內，隨根元素同時位移，看似與蝴蝶黏附的大圓球。  | 將8點移到同一錨點的獨立粉塵圖層，改為1–2px級視覺細粉，在蝴蝶飛過後向下、向後分散飄落。                 |
| 回歸融合 | 必須回到既有圓形光源中心才可銜接原火焰重燃。                   | 蝴蝶主體在49.6%回到`0,0`相對原點並淡出；既有圓形光源與火焰重燃時序不變。                               |

## 位置鎖定

蝴蝶本體與新粉塵容器均使用既有圓形光源的 `left: 34.3%`、`top: 7%`、`width: 34%`、`aspect-ratio: 1 / 1`。任何飛舞、拍翼與下落僅發生在這個容器內的相對位移，不改變原火焰 `left: 3.2% / top: -28%`、側光暈 `left: 27.4% / top: -7%`或任何既有位置值。

## 第一輪實機檢視

`live-340.png`確認蝴蝶本體已與雙翼獨立、能沿左下弧線離開火柴頭；`live-460.png`確認主體已進入回歸段。然而，獨立粉塵雖已脫離蝴蝶結構，實際390×844畫面中的亮核與尺度不足以清楚辨識，尚不符合影片的金色細粉拖尾。下一輪只會提高**獨立粉塵圖層**的z-index、白金亮核與1–3px級可見尺度，不改變粉塵容器、蝴蝶容器、原火焰或任何既有效果位置。

## 第二輪實機驗收

粉塵座標診斷確認原本CSS百分比位移誤套用至粉塵本身，已改為由粉塵容器的`left/top`相對位置計算。390×844實機量測顯示：在飛舞段34.2%，8點位於`x=78.52–92.81 / y=272.44–281.81`；在下落段39.1%，位於`x=75.91–90.22 / y=281.63–292.66`，表示已與蝴蝶中心`x=81.32 / y=274.65`脫離並向下飄落。細粉實際尺寸為約1.5–2.9px，維持細碎感而非大圓球。`live-390.png`與`live-460.png`確認蝴蝶先以左下弧線飛出、迴旋回歸，且49.6%前回到既有光源中心；原火焰、圓形光源、光環、煙霧、側光暈、外層餘暉及Logo位置均未變更。
