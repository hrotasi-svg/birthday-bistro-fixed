# 第209批次：第199批次蝴蝶基準回復與指定微調

## 範圍鎖定

本批次先以第199批次提交 `15ca2a5a` 為蝴蝶視覺基準。四翼輪廓、大小、原始位置、翼根、飛行路徑、蝴蝶容器、金粉容器、火焰、圓形光源、外層餘暉、Logo、文字、短按六色切換及520ms長按開關均維持既有設定。本批次只調整使用者明確指定的拍翅振幅、最高相位翼片間距與沿途金粉精細度。

## 第199批次基準與指定拍翅微調

四片花瓣翼均保留第199批次原始 `rotateY` 開合資料、輪廓、位置、尺寸、縮放基準與1.08秒同步週期。為縮小拍動幅度，最高相位僅覆寫主翼至 `rotateY ±56deg / rotateX 50deg`、副翼至 `rotateY ±50deg / rotateX 44deg`；中段補間已回復第199批次的 `/ 1.18`。這些值小於第199批次原始閉合姿態，同時保留原始翼形。

> 在外飛36%且四翼50%最高拍相位的實機固定量測中，左右主翼邊界間距為 **18.61px**，為正值；因此相鄰翼片不交叉或重疊。

重新載入後的第二次實機驗收得到相同的18.61px正間距；回復播放900ms後，240顆粒子池中共有62顆可見，七層分布依序為11、11、11、11、11、4、3顆。這確認大中小粒子均由同一實際尾端來源持續發射，而非固定天空位置。

## 金粉層次

金粉仍從蝴蝶翼後的實際尾端錨點發射，離開後獨立漂移與下沉。粒子池保留240顆，並採七層大小、生命週期與落下距離：3.4px、2.3px、1.55px、1.04px、0.70px、0.46px、0.28px。每輪發射的各層粒子使用不同閃爍週期，形成大中小、亮暗錯開的細碎金粉，而不使用固定天空座標。

## 驗收要求

完整循環須確認：第199批次四翼輪廓與飛行位置仍在；拍翅振幅較原始閉合姿態小；最高上拍存在正翼片間隙；外飛至回程均由尾端發射可辨識的大中小閃爍金粉；除指定特效外無其他設定變更。
