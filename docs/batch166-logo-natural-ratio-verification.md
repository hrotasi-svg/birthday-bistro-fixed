# 第166批次：新Logo原始比例驗收

本批次僅修正門店選擇頁新Logo的圖片顯示方式；使用者上傳的Logo資產、容器位置、容器尺寸、火焰與其他網站設定均維持不變。

| 驗收項目       | 最終設定                                         | 結果                                                   |
| -------------- | ------------------------------------------------ | ------------------------------------------------------ |
| Logo容器位置   | `left-[13.5%]`、`top-[29.6%]`、`w-[22.5%]`       | 完整保留。                                             |
| 原Logo框架比例 | `aspect-ratio: 775 / 954`                        | 完整保留。                                             |
| 新Logo圖片比例 | `object-fit: contain`、`object-position: center` | 依使用者上傳圖片原始比例置中顯示，不再填滿拉高或變形。 |
| 黑色覆蓋層     | `store-select-logo-glitch` 實際元素              | 維持移除。                                             |

已在390×844門店選擇頁實機畫面檢視，新Logo未向上拉高，且位於既有Logo容器位置。
