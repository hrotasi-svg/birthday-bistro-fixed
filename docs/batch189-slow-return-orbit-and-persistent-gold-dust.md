# 第189批次：後半段緩慢迴旋回原點與持續金粉

## 影片分格設計

參考影片的回程不是縮小後直接倒退，而是先由最高點轉向，再以S型小弧線朝原光源正向飛行。後半段維持中等大小，接近原光源才逐步減速與縮小；金粉始終留在飛行方向的後方，直到融合前仍然存在。

## 實作與實機驗收

後半段改為多段關鍵影格：38.5%開始轉向、40.5%與42.5%完成向下回弧、44.5%與46%繞Logo左側上行、47.2%與48.4%朝原光源作第二段弧線、49.2%與50.0%才進入減速縮小；50.4%才抵達原點。蝴蝶容器改為自訂緩動，避免直線速度。390×844實機量測顯示：48.8%蝴蝶仍在`x=75.40 / y=252.94`、尺寸約`11.74×14.11px`且金粉16點仍可見；49.6%仍有16點金粉；50.4%才融合消失並交由既有圓形光源閃爍／火焰重燃。Logo、文字、原火焰與所有錨點均未移動。
