## 第158批次實作判準

1. 完全移除 `.store-select-real-flame-halo` 的封閉輪廓與徑向漸層。
2. 燃燒時僅使用一條依附火焰右側外緣的短距離、柔邊線性亮帶；亮帶本身不可封閉、不可圓形、不可橢圓、不可水滴。
3. 吹熄段讓亮帶沿右方縮短並淡出；圓形燭芯光源單獨維持既有重燃時序。
