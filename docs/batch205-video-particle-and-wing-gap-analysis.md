# 第205批次：影片金粉與上拍翼片間距分析

本批次只處理門店選擇頁既有火焰蝴蝶循環中的金粉分層與上拍翼片交叉。第199批次四片花瓣翼的尺寸、位置、輪廓、翼根與飛行路徑維持鎖定；其他網站設定、既有效果位置與互動不得變更。

## 參考影片的可實作規則

兩支影片一致呈現：金粉由翅膀後緣離開，緊貼翼緣處最密，沿剛飛過的弧形路徑前濃後淡。粒子分為三個視覺層次：少量約 `2–4px` 的高亮閃點、構成主拖尾約 `1–2px` 的一般細粉，以及低對比、接近或小於 `1px` 的極細背景粉。轉彎時，粒子會承接尾端的切線方向向外側飄散，再在低重力下緩慢下沉；融合前則提高極細粉比例。

影片同時可見的粒子量顯著高於目前14顆單一粒子池，約介於50至100顆的分層效果，但不應以等距、等大小或天空式預鋪座標呈現。本次以受上限控制的動態粒子池產生多層金粉，維持實際尾端發射與獨立下落，避免大量無限制DOM節點。

上拍最高點的左右翼片形成小開口的V字頂端，翼尖接近但不交叉。修正方式只可調整該相位的深度分離與可見順序，不可變更第199批次四翼的外型、大小、位置、輪廓或翼根資料。

## 本次實作

動態粒子池由14顆擴增為120顆受控節點，並將沿途發射間距加密為原來的一半。每次從實際翼後尾端發射時，同步產生1顆高亮大點、2個主細粉尺度與1個極細粉尺度，因此整段飛行會形成前濃後淡、大小錯落的帶狀金粉，而不是單一等大小光點。粒子仍會離開尾端後獨立沿切線方向漂移，並以不同下沉距離與生命週期消散。

最高上拍相位只加入左右鏡像的暫時性 `translate3d` 間距與深度分離：左右主翼分別向外 `36%` 並於深度軸相差 `0.20rem`，副翼則各向外 `18%` 並保留較小深度差。四片花瓣翼的第199批次輪廓、大小、基礎位置與翼根資料均未改變。

## 實機修正依據

第一次實機量測確認四個金粉層級均有發射，但外飛早段僅約6顆、回程約35顆，仍低於影片的帶狀密度；同時主翼矩形邊界仍有約5.31px相交。因此已把動態粒子池提升至120顆，並把實際尾端發射間距從0.018縮短至0.009個循環進度。第二次最高上拍50%量測仍有3.93px邊界重疊，故只將暫時主翼鏡像外移調整至左右各64%，副翼為左右各32%。這些修正只影響金粉池與最高上拍的暫時變換，不改變第199批次翼形資料、容器位置或飛行路徑。

加密後實機量測：外飛中段有20顆可見金粉，回程有53顆，融合前有52顆，且四個尺寸層級均同時存在；這符合影片所需的前濃後淡帶狀分層，而所有粒子仍由實際翼後尾端發射。最高上拍50%最終量測，左主翼右邊界為 `316.667px`、右主翼左邊界為 `316.992px`，保留約 `0.325px` 的正V字間隙，因此相鄰主翼已不交叉或重疊。
