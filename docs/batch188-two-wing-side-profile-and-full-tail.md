# 第188批次：兩翼真側面蝴蝶與全程金粉

## 結構重構

本批次不再調低舊四翼的透明度，而是直接從JSX移除`upper-left`、`lower-left`、`upper-right`、`lower-right`四個翼元素。蝴蝶現在僅有`side-main`近側主翼、`side-far`淡化遠側翼及一個水平身體，共三個內部視覺元素；容器、火焰、圓形光源、Logo、文字和所有既有效果錨點均未變更。

## 390×844實機驗收

34%與35%連續畫面確認不存在正面四片對稱翼：畫面只有近側主翼與其後方較淡的遠側翼。近側主翼採1.12秒週期、遠翼採1.06秒且相位錯開，兩個連續影格可見近翼開合、遠翼延遲的側面慢拍關係，而不是以整隻蝴蝶旋轉代替拍翼。48.8%與49.6%的座標量測均保留16點金粉，並在蝴蝶回原點融合前維持可見；50.4%後才淡出，由既有圓形光源完成閃爍重燃。

48.8%實機畫面確認蝴蝶已接近原點而金粉尾流仍在後方下落；49.6%畫面確認蝴蝶重疊既有原光源後，圓形光源放大閃爍才開始接續。此段不調整任何Logo、文字、火焰、圓形光源或容器位置。
