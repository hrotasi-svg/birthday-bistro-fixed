# 第192批次：最新影片蝴蝶角度與回程金粉重製規格

## 分格交叉結論

三支最新參考影片的共同結構不是固定朝向的圖示沿平面路徑移動，而是機身先俯衝、轉向時側身收翼並翻面、回程再以仰角爬升。起飛段的機身約為俯衝傾角，近翼先收、遠翼縮小且延遲；轉向段的翼面收到最窄並以Y軸翻面，令飛行方向改變看起來是由身姿帶動；回程段機身調整為上揚傾角，近翼展開幅度較遠翼大，回到原點前逐步放平。

## 實作約束

本批次會完全替換既有蝴蝶DOM／CSS輪廓與飛行角度關鍵影格，但不會改變任何既有效果錨點、Logo、文字、火焰、圓形光源、外層餘暉、煙霧、互動、頁面、路由或資料。蝴蝶仍從既有容器原點起飛並回到同一原點；金粉容器亦維持既有位置。新的視覺以獨立近翼、遠翼與水平身體呈現側面透視；飛行容器的角度、翻面和位置分離控制，避免單純平移或四翼正面輪廓。

金粉採小型獨立元素與分組時間偏移，不使用圖片、影片或額外大量DOM。回程段將以獨立後段發射群維持顆粒產生，避免因前半段元素壽命結束而在回程完全消失。

## 初步實機量測

以390×844手機尺寸擷取新循環後，48.5%回程中段的蝴蝶中心約為x=102.96、y=332.53，八組回程細粉中可見八點，位置約在x=65.50至165.05、y=294.81至388.81之間，大小約0.88至2.79px，透明度約0.61至0.95。51.0%時仍保有六點回程細粉；53.6%時仍保有四點，證明粒子不再於後半段完全消失，並以獨立重力方向持續下落。轉向影格採Y軸翻面，回程機身維持仰角而非縮小直線倒退。

42.5%的實機影格顯示蝴蝶剛完成翻面時，兩翼以收翼後的側面姿態重新展開；45.5%的回程影格則顯示機身以仰角離開轉向點，並有六個可見金粉點在後方獨立下落。為避免Y軸翻面使翼面在回程被隱藏，翼面採可見背面處理；這不會增加額外翼片，因此結構仍保持近翼、遠翼及單一機身的側面輪廓。
