## 第154批次驗收決策

1. 重燃光源必須是**唯一一個**獨立光源元素，寬高均由同一尺寸定義，固定 `aspect-ratio: 1 / 1`、`border-radius: 50%` 與 `clip-path: circle(50%)`。
2. 光源必須位於原火焰 PNG 之上；光源出現的整段時間，原火焰 PNG 必須維持 `opacity: 0`，避免任何水滴／熱氣球形外框透出。
3. 光源僅使用非混色的同心圓 `radial-gradient(circle at 50% 50%, ...)`；中心需有足夠白金亮度，外緣自然透明，且不新增外部光圈、直線或星芒。
4. 只有在光源結束後，原火焰才以原始比例回復；不得在圓形光源段使用非等比縮放。
