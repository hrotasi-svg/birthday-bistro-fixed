# 第208批次：參考影片逐格對照基準

已擷取使用者新影片前段與後段共二十張連續影格，供外飛、上拍、下拍、回程與融合前對照。影片中的藍色蝴蝶不是整片翼面大幅直立再折回：每次拍翅維持淺而快速的側向折疊，翼尖在最高相位保有清楚間隙，不會跨越中央身體或互相覆蓋。外飛至回程期間，身體前進方向及翼片角度持續帶有微小變化，而非固定對稱的單一往返。

金粉在影片中不是均勻大量散點。其最亮、最密的細粉由翼後和腹部尾端剛離開的位置開始，形成窄的彗星尾帶；隨飛行距離逐漸展開、變小、變暗並下沉。回程仍維持連續細粉尾流，但密度低於尾端附近。第208批次網站對照須同時驗證：翼片最高點不交叉、拍翅只作淺折疊、金粉由尾端前濃後淡而非平均散布。

網站實機對照（外飛36%、翼拍50%）發現主翼矩形邊界間距為 `-9.002px`，代表儘管前一批已降低有效角度，現行最高相位仍有實際重疊，與影片中翼尖不接觸的畫面不符。此結果確認下一步不能只修改角度數值，還必須在最高相位保留可量測的視覺間隙；暫停當下有2顆既有金粉可見，亦不足以呈現影片尾端前濃後淡的連續細粉帶。

第一次候選量測未改變矩形結果，原因是即時測試時左右鏡像外移的正負方向與原始CSS規則相反；此數據不可作為最終角度決策。下一次量測必須維持左翼負X、右翼正X的原始鏡像方向，才可取得可用的間距數據。

實作決策：網站原始有效Y閉合角度仍保留約76至82度，會使翼面在上拍時折疊得過深，與影片的淺側向折疊不同。因此改以主翼±52度、副翼±44度的有效Y閉合角度，並把有效X閉合改為主翼24度、副翼20度；最高相位左右主翼向外移至±105%、副翼至±52%，目標是讓V字開口可量測而非僅靠深度排序。金粉改為六層短生命週期粒子：近尾端由2.6px亮點與1.7px主細粉主導，外緣逐層降至0.34px，並在動畫前段快速變暗、後段緩慢下沉，形成影片中的窄彗星尾帶。

更新後第一次實機同步等待外飛與翼拍的指定相位未在30秒量測視窗內同時命中，因此未採用該次逾時結果。後續驗收將以固定設定動畫時間並暫停的方式取得可重現的最高上拍與回程金粉畫面，再量測翼片邊界及可見粒子。

固定相位量測須包含動畫的3.6秒延遲。修正延遲後，在外飛36%、翼拍50%時，現行主翼角度確為Y±52度／X24度，但主翼矩形V字間距達 `104.346px`，過寬，並非影片中的淺開口。因此最高相位外移已由±105%收斂至±20%（副翼±10%），以保留正間隙而貼近影片的淺折疊姿態；下一步會以同一固定相位重新量測實際間距。

相同固定相位重新量測顯示±20%主翼外移反而仍有 `-20.396px` 的負間距，代表翼片重疊。以±105%與±20%的兩次同條件量測插值，設定主翼±40%、副翼±20%可形成小型正V字開口，既避免影片不允許的交叉，也不會出現±105%過寬的分離姿態。金粉在手動暫停前尚未發射，故此相位不以零粒子誤判密度；回程會另以正常播放量測。

最終實機對照：外飛36%、翼拍50%時，主翼有效Y／X角度為 `-52deg / 24deg`，主翼間距為 `8.955px` 正值，形成淺V字開口且無重疊。恢復正常播放至回程48.4%時，有54顆可見實際尾端金粉，六層分布分別為8、9、10、11、10、6顆；這使最亮的尾端層較密、外緣細粉逐層遞減並緩慢下沉，符合影片的彗星尾帶方向而非平均散點。
