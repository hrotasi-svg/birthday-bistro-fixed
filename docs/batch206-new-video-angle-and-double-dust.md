# 第206批次：新影片拍翅上限與加倍金粉

使用者新影片顯示蝴蝶上拍不會直立或越過中線：外飛的最高上拍約為60至70度，回程約45度，融合前約20至30度。翼尖維持清楚的V字開口，從不交叉或重疊。因此本次只會將既有上拍關鍵影格的最高旋轉上限收斂至60至64度範圍，並調整中間補間節點，避免先前在37.5%等節點超過最高角度。

影片的金粉同時可見量約為60至100顆，具有大亮點、主細粉及背景細粉。使用者要求直接加倍，因此會把既有實際翼後尾端粒子池由120顆增加至240顆，並把發射間距再縮短一半；所有粒子仍由實際尾端出發、沿飛行切線拖尾、再逐漸下沉，不使用天空固定座標。

實作採用主翼最高上拍 `64deg`、副翼最高上拍 `58deg`；原本會推高至約75度以上的補間節點會隨之同步收斂。動態金粉池調整為240顆，發射間距從0.009縮短為0.0045個循環進度，以直接倍增沿途可見密度。

實機量測結果：外飛中段有42顆可見金粉、回程有91顆、融合前仍有79顆，符合新影片約60至100顆活躍金粉的密度範圍；全部粒子仍由實際翼後尾端發射。最高上拍約50%相位，主翼左右矩形邊界保留 `7.507px` 正V字間隙，且有效主翼最高上拍上限已由78deg收斂為64deg，未再出現過頭、交叉或重疊。
