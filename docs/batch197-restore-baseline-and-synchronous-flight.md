# 第197批次：回復第195基線後的同色同步翼面與平緩回程

本批次依使用者要求，先只回復門店選擇頁蝴蝶至第195批次的四片獨立花瓣翼與原回程基線。原火焰、外層餘暉、圓形光源、光環、側光暈、煙霧、Logo、文字、互動、金粉容器與所有既有位置均不在回復範圍內。

兩支影片一致顯示：蝴蝶不是左右翼各自動作，而是同色鏡像的同步扇動；回程必須以由快至慢的長弧線收束，最後才與既有圓形光源融合。

第三支影片交叉確認相同結論：起飛具短暫爆發力、轉彎維持平順勻速、回程採明顯的快－平－慢節奏；接近原點時速度降至最低，左右翼不出現任何相位滯後或異色分離。金粉在回程尾段加密，並僅於蝴蝶到達既有融合點後與光源交匯。

## 手機尺寸實機驗收

第197批次以390×844手機尺寸擷取回程密集影格。約55.0%影格中，四片翼面的色相與明暗規則一致，採同一時間軸鏡像開合；約58.0%影格中，蝴蝶已縮至既有火柴頭前的短距離，並在既有圓形光源放大前保持低位移收束。此驗收僅檢查蝴蝶容器內動畫，不調整火焰、光源、Logo、金粉容器或任何既有效果錨點。
