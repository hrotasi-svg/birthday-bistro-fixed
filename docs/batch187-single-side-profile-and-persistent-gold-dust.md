# 第187批次：單一側面蝴蝶與持續金粉

## 設計依據

參考影片的側面飛行只呈現兩個可辨翼面層次：一個近側主翼與一個較淡、延遲的遠側翼，並沒有正面四片對稱翅膀。本批次保留右側近翼的主翼與副翼，將左側兩翼降至`0.10 / 0.06`可見度，身體改為水平長橢圓，從畫面上讀作側面頭部／腹部，而不是垂直正面身體。

## 實機驗收

390×844的34%與35%連續影格確認，蝴蝶以右側近翼為主，左側僅保留淡化深度殘影；相鄰影格的近翼展開程度不同，表現為慢拍開合而非整隻晃動。金粉量測在48.8%仍有16點可見（約0.51至1.22px）；49.6%回到原光源時仍保留16點細粉（約0.41至1.02px），到50.4%才完全淡出，符合「持續灑落至回原點融合前」的要求。圓形光源、原火焰、Logo、文字與所有錨點均未移動。

48.8%與49.6%實機畫面確認金粉時序確實持續到圓形光源融合前；為使手機實際畫面中的末段細粉更清楚，後續僅提高晚段粒子的亮度與尺度，不調整金粉路徑、數量、容器位置、蝴蝶或光源位置。

提升後的390×844量測顯示：48.8%的16點金粉仍以約`0.75–1.86px / opacity .42`分散於蝴蝶尾端後方；49.6%融合光源放大時，16點仍以約`0.60–1.48px / opacity .25`持續可見；50.4%才完全淡出，之後由既有圓形光源銜接火焰重燃。實機畫面確認光源、Logo、文字與原火焰錨點均未移動。
