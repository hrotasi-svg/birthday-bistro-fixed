# 第207批次：影片式小振幅拍翅

使用者指出先前上拍幅度仍遠大於影片，因此本次不再以64／58度作為有效最高值。既有四翼輪廓、位置、飛行路徑、身體、觸鬚與240顆實際翼後金粉池均保持不變；只把有效主翼最高上拍收斂至40度、副翼收斂至36度，使主翼振幅由54度降為30度、副翼由50度降為28度。

同時修正原本37.5%／62.5%補間會以除數1.18產生高於終點的角度，改為1.45，確保中間影格不會超過設定上限。動畫緩動改為柔和的非線性曲線，避免線性往返造成硬板感。最高上拍時保留既有鏡像V字間距規則，以防止翼片交叉或重疊；金粉發射池、尺寸、密度與沿途下沉完全不變。

實機量測結果：最高上拍有效主翼為 `40deg`、副翼為 `36deg`，相較上一批的64／58度已明顯縮小；主翼左右邊界仍保留 `9.117px` 正V字間距，未交叉或重疊。回程區段仍有96顆可見、由實際翼後發射的金粉，故本批未降低金粉數量或改變其沿途下沉機制。
