# 第184批次：獨立拍翼、原點融合重燃與金色細粉

## 鎖定範圍

本批次只變更`.store-select-flame-butterfly`的內部四翼拍動、既有圓形光源／圓形光環的循環時序、原火焰重燃時序及`.store-select-flame-gold-dust`粒子。原火焰`left: 3.2% / top: -28%`、外層餘暉、圓形光源與圓形光環`left: 34.3% / top: 7%`、側光暈、Logo、文字、背景、互動及其餘網站設定均未改動。

## 影片分格對照與實作

參考影片顯示上拍時翼面收窄、翼尖接近，下降展翼時翼面顯著放大；左右翼於轉向段不完全同步。為避免「整隻蝴蝶晃動」的表現，主容器路徑移除了大幅旋轉，只保留輕微姿態方向；四片上／下左右翼分別以`rotateY(±76deg)`收翼與`rotateY(±8deg)`展翼、0.224至0.281秒不同節奏拍動。390×844的34%與35%連續實機影格顯示，在相同文字穿越弧線上，翼面可見輪廓已由展開變為收窄，身體並非以整體旋轉代替拍翼。

## 融合與細粉時序

蝴蝶回程最後15%才開始縮小，49.6%重疊既有原光源；圓形光源與光環於47.6%只作微弱預熱，49.6%才達到放大閃爍峰值。原火焰在48.8%與49.6%維持隱藏，50.4%才低不透明度萌發，確保順序為「蝴蝶回原點 → 光源閃爍 → 火焰重燃」。金色細粉改為16點、約1.2至1.8px的高亮小點，與蝴蝶同步起始且在翼後緣／腹部尾端向下分散，52%前完全消失，避免沒有蝴蝶時仍殘留粒子。

390×844的48.8%實機畫面確認蝴蝶已縮回火柴頭原點，圓形光源正進入融合閃爍，畫面中原火焰仍未提前出現；52.2%畫面才確認原火焰由該光源向上重新生成。此順序符合本批次「蝴蝶飛回原點後才融合光源、閃爍、再次成為火焰」的驗收要求。
