# 第201批次：蝴蝶結構、拍翅角度與沿途金粉

本批次只修改門店選擇頁火焰蝴蝶循環中的四項指定效果：金粉沿實際飛行路線灑落、身體緊連翼根中心、兩根細觸鬚、以及四翼以平行基準上／下60度拍動並略增頻率。

正式站已重新載入並進入既有門店選擇頁。後續驗收會以手機尺寸連續影格比對外飛、轉向和回程；不修改任何其他頁面、文字、資料、互動、Logo或既有效果位置。

本輪正式站重現完成後，確認只針對蝴蝶循環內的金粉來源、四翼與中央身體／觸鬚結構進行修正；其他頁面和既有錨點不納入修改範圍。

開發預覽已完成資料載入並進入既有火焰循環。後續驗收以同一門店選擇版面中的動態粒子、四翼、中央身體與雙觸鬚為準。

外飛中段固定取樣時，蝴蝶中心約為 x=664.15、y=953.27，已啟動的動態金粉位於其後方約 x=630.48、y=966.51。金粉先自翼後位置出現，再由自身動畫獨立向下漂落；既有固定座標金粉視覺層已停用。

最新開發預覽已重新載入。外飛、轉向與回程會在同一手機尺寸下固定時間軸取樣，以驗收翼後錨點粒子和蝴蝶結構的可見關係。

外飛約36%時，翼後錨點位於約 x=650.50、y=942.38；多批動態金粉自此後方留下前段飛行軌跡，最近一批仍緊接於約 x=630.85、y=915.85。回程約54%時，翼後錨點已位於約 x=185.28、y=909.36，前批金粉已依獨立生命週期淡出，未再從固定天空或容器中心出現。

外飛中段實機畫面確認蝴蝶維持於既有弧線與門店選擇頁版面中，Logo、文字、原火焰與其他效果位置均未移動；下一步以放大影格檢查身體、觸鬚及拍翅的細部可見性。

明確±60度拍翅版本已重新載入開發預覽，並保持同一頁面背景、Logo、文字、原火焰與既有錨點不變。

固定外飛拍翅相位量測確認四片翼均存在；中央身體實際約 10.19×13.14px，兩根細觸鬚各約 2.36px 寬。四翼使用同一同步拍翅動畫，並以平行 0 度為中線，設定於 -60 度與 +60 度之間往返。
