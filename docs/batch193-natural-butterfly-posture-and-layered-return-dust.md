# 第193批次：自然蝴蝶姿態與分層回程金粉規格

## 修改範圍與固定限制

本批次只調整門店選擇頁火焰循環中的蝴蝶內部身姿、飛行傾角、近遠翼透視與金色細粉。既有容器錨點、火焰、圓形光源、光環、Logo、文字、背景、互動與所有其他頁面維持原狀。

## 三支影片逐格交叉結論

三支影片均呈現單一側面蝴蝶，而非正面四翼。蝴蝶的機身方向需持續跟隨飛行曲線改變，不可只讓整個圖形平移。近翼與遠翼的可見比例在掉頭時交換：外飛由近翼主導，轉向期間收翼、由Y軸平順翻面，回程則由原遠翼成為主翼。

| 蝴蝶局部時間 | 姿態與翼面                                               | 對應實作規格                                             |
| ------------ | -------------------------------------------------------- | -------------------------------------------------------- |
| 0–15%        | 機身仰角約15–30度，近翼略大，起飛拍翼快                  | 由原點連續抬頭，近翼展幅大於遠翼，短促拍翼。             |
| 15–35%       | 機身爬升至約45度，遠翼縮至近翼約40–50%                   | 以多個小角度節點取代一次性旋轉，機身與翼面同步傾斜。     |
| 35–50%       | 姿態漸近水平，翼展較大、拍翼慢                           | 以滑翔段消除最高點急煞與僵硬轉向。                       |
| 50–70%       | 機身由輕微俯角漸轉約30度俯角，翼面收合並連續Y軸翻面      | Y軸翻面在多個節點完成；近遠翼權重交接，非瞬間切換。      |
| 70–85%       | 回程沿曲線加速，機身以約45度俯衝／回正的連續姿態飛向光源 | 使用回程軌跡切線角度，近翼改由反向翼主導並恢復較快拍翼。 |
| 85–100%      | 接近光源時收翼、回正、縮小融合                           | 角度與翼展漸收，光源放大脈衝與既有重燃時序維持。         |

## 金色細粉重製規格

金粉不能以單一均質粒子層呈現。外飛需為較高密度的火焰翼緣噴發；回程密度較低但必須持續，且以前景較大亮點、背景針尖微粒及中景柔和火星形成景深。各粒子的延遲、亮度、尺寸、水平漂移、重力下落與淡出均需不同；轉向時加入短暫聚集亮閃，回程末段仍保留少量殘粉直至融合。

| 粒子層   | 目的                       | 尺寸與亮度                | 時序與運動                                     |
| -------- | -------------------------- | ------------------------- | ---------------------------------------------- |
| 背景星塵 | 形成持續細緻尾流           | 約0.45–0.95px、低至中亮度 | 數量最多，延遲發射，緩慢下墜並隨機淡出。       |
| 中景細粉 | 顯示蝴蝶拍翼噴發           | 約0.9–1.65px、中高亮度    | 外飛與回程都分批釋放，略向後偏移後受重力下落。 |
| 前景亮點 | 提供影片中的焦點閃光與深度 | 約1.45–2.65px、高亮度     | 數量少、亮滅較強、漂移與下落距離較大。         |
| 轉向閃粉 | 連接翻面與回程             | 約0.7–1.45px、高亮度短閃  | 在翻面中段短暫聚集，隨後分散下落。             |

回程粒子自蝴蝶轉向前開始錯開發射，最後一組維持至蝴蝶融合前；粒子仍以獨立重力軌跡下落，不跟隨蝴蝶本體移動。

## 第193批次實機檢視

以390×844手機尺寸檢視42.5%轉向影格，可見蝴蝶完成Y軸翻面後以收翼側身姿態離開轉折點，附近同時保有轉向聚集的亮點與細微背景星塵。45.5%回程影格中，蝴蝶以反向側身沿Logo左側回飛；原回程粒子之外，新增的背景星塵與前景亮點形成不同尺寸、亮度與下落距離的尾流，避免回程只剩少量同質圓點。擷取的回程後段量測顯示，約54.7%仍可見14個不同層級粒子，56.3%仍可見10個，58.0%光源融合前仍留有3個殘粉。

54.8%影格顯示蝴蝶已收翼並接近火柴頭左上方，仍有多層金粉沿獨立重力方向向下延伸；56.2%影格中，既有圓形光源開始放大，蝴蝶已淡出並讓殘粉自然融入同一光源。這兩段均未改動圓形光源錨點、Logo或原火焰重燃時間。
