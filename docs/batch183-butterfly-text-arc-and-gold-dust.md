## 參考影片與現行畫面的差距

參考影片的蝴蝶於火焰熄滅後立即成形，雙翼以每秒約4至5次的可辨識拍動推動身體先上升、再跨越文字附近的空間；到達弧線頂點時，以左右翼不對稱拍動轉向，最後向下回到原光源。金色細粉由腹部末端與翼後緣脫離，呈細碎、疏密不同的下落拖尾，而非固定黏附的亮點。

現行390×844實機量測中，「您的生日」文字框為`x=179.05–330.56 / y=286.31–303.11`；蝴蝶飛行段34%僅位於`x=80.83 / y=273.72`，沒有接近文字。這是本次最主要的路徑差距。重製後的主弧線需於約34%至37%將蝴蝶中心推至文字框左緣附近且高度越過文字，之後向右下迴旋回既有原點`x≈97.65 / y≈266.34`。

## 重製驗收目標

蝴蝶本體必須由獨立身體、上翼與下翼形成較明顯的輪廓；左右翼採不同節奏、不同展開角度，並於轉向段改為不對稱拍翼。飛行段將由原本左下短弧線，改為「火柴頭起飛 → 向右上跨過您的生日文字附近 → 頂點轉向 → 右下回原光源」的弧線。細粉改為獨立粒子：起始於翼後緣及腹部尾端，逐批延遲出現並只受重力往下飄落，不再套用與蝴蝶相同的本體位移。

## 重製後首次實機檢視

在390×844實機畫面中，34%飛行段的蝴蝶已位於「您的生日」文字左側並以展翼姿態越過文字附近；39%轉向段可見蝴蝶完成右向弧線的頂點轉向。12點金色細粉同時分布於蝴蝶的後方及下方，而不是與蝴蝶中心重疊；其可見亮點約0.6至1.3px，保留影片中的細碎飄落感。回歸段48.8%量測蝴蝶中心已回到`x=101.06 / y=266.34`，接近既有原光源中心`x=97.65 / y=266.34`，後續由既有圓形光源放大及原火焰重燃銜接。
