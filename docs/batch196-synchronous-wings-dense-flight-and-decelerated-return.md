# 第196批次：逐偵同步拍翼、密集飛行與平緩回原點

本批次僅處理門店選擇頁既有火焰循環內的蝴蝶翼面同步、飛行節點連續性及回原點速度。原火焰、外層餘暉、圓形光源、光環、側光暈、煙霧、Logo、文字、互動、金粉容器及所有既有效果錨點均不得變更。

## 三支最新影片的交叉逐偵規格

三支影片皆顯示左右翼為中心軸鏡像、**零相位差**的完全同步拍動；左右主翼與副翼必須共用同一時鐘與同一拍動關鍵影格，僅以鏡像方向區分。單一拍翼週期採約 0.8 至 1.0 秒：0–20% 為快速下撲，20–35% 為最低點短暫停留，35–85% 為較慢的上揚收合，85–100% 回到最高點並準備下一拍。

飛行路徑必須維持既有空間位置，但以密集節點消除跳格。起飛附近 0–20% 與回原點前 75–100% 使用最高節點密度；巡航段以連續圓弧維持視覺滑行；75% 後不得直線加速回縮。回程速度採分段減速：75–85% 下降至峰值約 40–60%，85–95% 顯著緩慢收束，95–100% 幾乎停駐並以極小幅度收翼完成與原光源融合。

## 驗收條件

使用 390×844 實機影格在相鄰拍翼相位、轉向、回程中段及融合前比較。每一組左右對應花瓣翼必須同時展開或收合；相鄰飛行影格必須呈現連續位移；55% 後每一段到原點的位移距離應逐步縮短，直到既有圓形光源放大與火焰重燃。

## 第196批次實機逐偵驗收

390×844 實機擷取在回程 55.0% 與 55.4% 的六倍放大影格中，左右鏡像翼組共用同一拍動姿態；兩張相鄰影格皆呈對稱收合輪廓，而不是左右側各自延遲。蝴蝶中心從較外側逐步往火柴頭方向移動，未見舊版回程末段的大距離跳回。後續將以 56.2% 至 58.4% 的更高密度影格確認最終融合前的位移持續縮短。

56.2% 與 57.4% 放大影格進一步顯示，蝴蝶在既有火柴頭上方持續以縮小、收翼的狀態靠近，不使用突然放大的火焰或直線倒退取代回程。57.4% 時才進入既有圓形光源的融合畫面；融合後由原本光源與火焰重燃接手，並未改變既有火柴頭位置或光源時序。
