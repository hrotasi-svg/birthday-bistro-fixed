# 第186批次：Logo左側側面繞行驗收

390×844實機量測確認蝴蝶回程已由Logo左側經過：43%中心約為`x=96.13 / y=338.49`，46%中心約為`x=47.78 / y=296.96`；Logo舞台範圍維持`x=52.64–140.39 / y=243.88–351.89`，未移動Logo、文字或原光源。

首次34%與43%畫面同時顯示，目前主容器的`rotateY(±68deg)`令側面縮得過窄，在手機上不足以辨識慢拍翼面。後續僅把側面角度收回至`±42deg`並放大主翼在側面可見的X尺度，保留同一Logo左側路徑、同一回原點時序及所有既有效果位置。這不是正面雙翼；目標是使側面主翼可見、遠側翼較淡且輪廓仍有深度。

調整後34%與35%連續影格顯示蝴蝶在「您」字左側的主翼已可辨識；相鄰影格中上／下翼的展開比例不同，主體路徑只前進而沒有用整隻旋轉模擬拍翼。43%與46%量測仍維持Logo左側回程：中心分別約為`x=96.25 / y=338.52`與`x=47.66 / y=297.28`。既有Logo、文字、火焰與圓形光源錨點均未改動。

496ms節點的390×844實機畫面確認：蝴蝶已縮至原光源，既有圓形光源／光環在火柴頭原點放大閃爍，火焰保持隱藏；522ms節點才確認原火焰從同一位置重新生成。量測的放大光源寬高約為`50.41px`，原點中心仍為`x=97.65 / y=266.34`，證明光源未刪除或移位。

36%實機飛行畫面確認金粉維持大小混合，沿蝴蝶尾端後方散開；43%畫面確認蝴蝶位於Logo左側、與Logo主圖分離，金粉不與蝴蝶身體或Logo黏合。粒子採各自的閃動延遲，並在回原點前完全淡出。
