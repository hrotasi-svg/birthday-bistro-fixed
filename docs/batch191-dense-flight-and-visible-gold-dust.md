# 第191批次：密集連續飛舞與可見全程金粉

## 影片分格與實作

依參考影片的16個以上時間分段，本批次將原本十餘個稀疏飛行節點改為約45個密集位置／姿態節點。前半段從25.6%至36.5%以細小增量向右上弧線飛行，中段37.3%至48.5%逐步轉向及下降，回程49.3%至58.4%再沿Logo左側多段回弧至原光源。主容器採線性時基，由密集且連續的空間節點自行控制速度，避免單一大緩動曲線導致折線或直線倒退。

金粉保留16點、大小混合及各自閃動，但加入四組0至0.54秒錯開尾流時間。每組從蝴蝶尾端以不同相位下落，使回程時仍有可見顆粒。實機390×844量測顯示，58.0%仍有16點可見，粒子約0.76至2.24px、透明度約0.32至0.67，較前版末段明顯。

## 初步實機檢視

39.5%與48.5%畫面顯示大小不一的金色亮點已分散於Logo及文字附近的蝴蝶後方，並沿下方尾流延伸；粒子不再因同一時基而同時消失。後續驗收將集中於前半段側面蝴蝶輪廓、密集節點的連續位置變化，以及融合前最後一段金粉與圓形光源銜接。

34.0%與36.0%兩張連續實機影格確認蝴蝶自文字附近繼續向右下弧線移動，翼面位置及後方亮點帶均產生連續變化。金粉在兩張畫面中保有不同尺寸與不同明暗的粒子，並非單一固定圓球或同步淡出。
