## 影片節奏對照

| 影片階段 | 蝴蝶與光點行為                                                   | 第181批次對應方式                                                    |
| -------- | ---------------------------------------------------------------- | -------------------------------------------------------------------- |
| 0%–15%   | 火焰縮小、凝聚為半透明蝴蝶；起點光點最密。                       | 在既有熄滅完成後，從原火柴頭位置展開雙翼與少量金色點。               |
| 15%–45%  | 蝴蝶拍翼，向左下以柔和弧線滑行；光點形成追隨路徑的光尾。         | 使用不改錨點的容器內相對路徑與不同相位雙翼，限定少量金點。           |
| 45%–75%  | 蝴蝶在左側大半圓迴旋，拍翼加快；光點較分散。                     | 在同一容器內以迴旋相對位移和縮放呈現，不建立大量DOM。                |
| 75%–100% | 蝴蝶回到起點，雙翼收攏、融合光源，火焰重生；餘下光點向中心匯聚。 | 回到原火柴頭相對原點並在既有圓形光源顯示前淡出，交由原火焰循環重燃。 |

金色光點只使用少量固定元素，不會成為煙火或星空；每一點具有不同大小、延遲和不透明度，以保留影片的細碎金色拖尾感。

## 輕量化實作設計

蝴蝶容器使用與既有圓形光源完全相同的錨點 `left: 34.3% / top: 7% / width: 34%`，只透過容器內相對位移形成飛舞迴旋，因此不會改動任何既有效果位置。蝴蝶本體只使用一個元素及其兩個偽元素製作左右火焰翼；8個固定金色點以不同的相對延遲和落點形成細小拖尾。總共增加9個非互動視覺元素，不新增圖片、影片、Canvas或大量DOM。

| 元素       | 動畫角色                                                                           | 同步原則                                      |
| ---------- | ---------------------------------------------------------------------------------- | --------------------------------------------- |
| 蝴蝶本體   | 在原火焰縮小的24.4%後從火柴頭展翼，於25%–49.6%完成左下滑行、迴旋、右向回歸與收翼。 | 採用既有`7.166s linear 3.6s infinite`主循環。 |
| 左右火焰翼 | 使用不同時長和延遲的收展動作，不同步拍動。                                         | 僅在蝴蝶本體可見期間呈現。                    |
| 金色光點   | 由蝴蝶起點密集、飛舞時沿路徑下落與分散、回歸時向中心收攏。                         | 固定8點、不同大小／延遲，停留在蝴蝶容器內。   |
