# 第185批次：側面蝴蝶、Logo繞行、圓形光源與金粉

## 鎖定範圍

本批次只允許調整火焰蝴蝶的內部外觀／飛行關鍵影格、既有圓形光源與光環的可見時序、原火焰重燃時序及金粉粒子。原火焰`left: 3.2% / top: -28%`、外層餘暉、圓形光源／圓形光環`left: 34.3% / top: 7%`、側光暈、Logo、文字、背景、短按六色、520ms長按及所有其他設定均維持不變。

## 影片分格準則

參考影片的蝴蝶全程為**側面輪廓**，非正面展雙翼；在側面中，翅膀約每0.8秒慢速開合一次，收合時寬度窄、展開時寬度增加。蝴蝶以正向向右飛出，經過文字後採大半徑橢圓弧繞回，而不是縮小後沿原路倒退。放大圓形光源必須留在出發點；蝴蝶回歸重疊時觸發最大亮度脈衝，之後才重燃。金粉同時要有微小細粉與稍大的閃點兩種尺寸，自翼後緣及腹部尾端灑落，個別閃動約0.5秒後消失。

## 390×844座標與弧線目標

實機量測：原光源中心為`x=97.65 / y=266.34`；「您的生日」文字框為`x=179.05–330.56 / y=286.31–303.11`；Logo舞台為`x=52.64–140.39 / y=243.88–351.89`。側面蝴蝶路徑將採：火柴頭起飛 → 以側面朝右跨過「您」字的左側附近 → 向右下通過文字 → 轉為左向側面，沿文字下方回到Logo右側 → 以左上弧線繞過Logo上緣 → 回到原光源。此路徑只改蝴蝶本體的`transform`，不調整文字或Logo位置。

## 首次側面慢拍實機檢視

390×844的34%與35%連續影格確認蝴蝶已在「您」字左側，以右側主翼、較淡的對側翼、腹部身體構成側面輪廓；左右翼採0.80至0.92秒不同開合週期，影格間翼面寬度為慢速變化而非正面快速對稱拍打。金粉位於蝴蝶後下方，並未與主體重合。後續將另行確認此軌跡在轉向段通過Logo上緣及回到原光源時的放大圓形光源融合。

39%實機畫面確認蝴蝶已由文字區域轉向左下；46%畫面確認其沿Logo右側／上方附近縮小回原光源，而非沿原出發線直接倒退。Logo與文字容器均保持量測時的原位置與尺寸。回歸後將以既有同一錨點的圓形光源放大脈衝銜接重燃。

496ms節點的390×844實機畫面確認蝴蝶已縮至原光源，既有圓形光源與圓形光環在同一火柴頭位置放大脈衝，並未移除；隨後522ms節點確認原火焰從同一位置重燃。金粉以16點大小混合亮點出現，在飛行中由尾端向下分散，並透過獨立0.54秒明滅關鍵影格逐一閃動後消失。
