# 第190批次：完整飛舞循環與全程金粉

## 影片時序設計

依參考影片逐格分析，蝴蝶在最高點後不應立即縮小，而要持續拍翼、以大弧線與小S型回原點；金粉自起飛持續至融合前，原點光源要在蝴蝶已回到火柴頭時才放大閃爍，之後再重燃。第190批次已將融合窗口由約50%延後至58%，並讓火焰、圓形光源、側光暈及金粉同步延後。

## 首次長回程實機檢視

390×844的51.0%與54.8%實機畫面確認蝴蝶已不再沿原路直線倒退，而是位於Logo左側不同高度後緩慢向原點回弧；金粉仍在後方下落。然而，54.8%畫面中的側面輪廓在中段縮小得過早，視覺上不足以讓使用者清楚看見「持續飛舞」。後續僅會提升既有回程節點的`scale`，讓蝴蝶在54.8%前保持可辨識大小；不改變任何`translate3d`路徑、元素位置、Logo、文字、光源或網站設定。

提升後51.0%與54.8%連續實機畫面確認，蝴蝶保有較清楚的側面輪廓，先經Logo左上方、再以第二段弧線靠近火柴頭；兩格位置不同，沒有縮小後直線倒退。金粉仍在回程後方並按個別閃動時序下落；58.0%才接續既有放大圓形光源，60.8%以後才由同一原點重燃火焰。Logo、文字、火焰、圓形光源及其既有位置均未變更。

580ms實機畫面確認蝴蝶完成回原點後，既有圓形光源在火柴頭上方放大脈衝，火焰尚未顯示；608ms畫面確認原火焰已從同一火柴頭位置重燃。完整循環的可見順序為：火焰縮小 → 側面蝴蝶飛出 → 最高點轉向 → 逐段緩慢回弧 → 金粉持續 → 圓形光源融合閃爍 → 火焰重燃。
