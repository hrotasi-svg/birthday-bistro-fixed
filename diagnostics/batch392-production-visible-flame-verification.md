# 第392批次：正式熄火火焰可見性驗證

## 正式頁傳播與自然循環

第392前景融合版本發布後，第一次正式頁載入仍顯示舊的`z-index:5`快取。等待25秒並以新的查詢參數重載後，正式DOM確認新熄火輸出層為`z-index:7`，真實火焰維持原本`z-index:6`。

在自然共同循環約`15.45%`（位於既有`12.9%–20.31%`熄火顯示窗、亦是原真實火焰最後完整一秒範圍）量測如下：

| 項目 | 正式頁結果 |
| --- | --- |
| 新熄火輸出 | opacity `.94`、z7、1,223個非透明Canvas像素。 |
| 真實火焰 | opacity `.99`、z6。 |
| 融合幾何 | 新熄火外層與真實火焰外層的x、y、寬、高完全相同。 |
| 原始MP4 | readyState `4`、播放中、自然畫格約`.352s`；使用既有原始檔而未改寫。 |
| 色相 | 新Canvas與真實火焰使用相同`hue-rotate(var(--store-select-flame-hue)) brightness(1.12) saturate(1.16)`。 |
| 控制台 | 重載後未見來源讀取、跨來源或Canvas繪製錯誤。 |

## 範圍確認

本批只新增高亮冷色火苗的透明輸出保留，並將**新熄火透明Canvas**置於既有真實火焰前方，以避免被其繪圖區遮蔽。未改原始MP4、真實火焰、原始蝴蝶GIF、內外餘暈、Logo、煙霧、水面原始播放、金幣、資料庫、其他頁面或16.311秒共同循環。
