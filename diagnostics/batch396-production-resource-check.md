# 第396批次：正式資源入口檢查

本紀錄只保存正式網域的客觀資源檢查，不構成使用者驗收，亦不改變任何網站設定。

## 結果

第396保存版本 `bf4ff192` 後，以新的查詢參數重新開啟正式 `/store-select`，頁面仍載入原生 `<video>`，來源仍是使用者上傳的熄火MP4，且已沒有先前的熄火Canvas元件。

但正式頁的計算顯示樣式仍是舊版幾何：子層計算 `left` 為 `16.5px`（舊規則 5%）、`top` 為 `-123.312px`（舊規則 -55%）、寬度為 `283.922px`（舊規則 86%），裁切仍為 `inset(68% 26% 15% 58%)`。這不是第394已保存的 `left:18.8%`、`top:-18.8%`、`width:57.6%`、`inset(59.1% 43.7% 4.6% 44.2%)`。

保存後等待35秒，再以無快取HTML請求檢查，正式入口仍引用：

- `/assets/index-Dxac2mvc.js`
- `/assets/index-j0cR6TYF.css`

最後再等待65秒，以 `Cache-Control: no-cache, no-store, must-revalidate` 與全新查詢參數直接取得正式HTML，結果仍為相同兩個舊資源雜湊。故此次已停止重複保存／發布嘗試；在正式入口實際切換前，任何額外熄火定位修改都無法讓使用者於正式網域看見，且會違反「除明列內容外不得變更」的範圍限制。

另作唯讀遠端連線檢查時，專案 `origin` 的 `git ls-remote origin HEAD` 無法完成，回傳「could not read Username … terminal prompts disabled」。此結果表示目前工作環境無法以非互動方式讀取正式發布使用的遠端；本次沒有嘗試變更遠端URL、帳號、權杖、任何憑證或部署設定。

因此正式網域仍在供應第394之前的前端資源。這是正式入口／資源傳播未切換，不能解讀為使用者瀏覽器快取，亦不能將第395-1至395-3、394-4或396-4標記完成。
