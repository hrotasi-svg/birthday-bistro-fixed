# 第404批次：開發驗證紀錄

本批次只允許三項變動：將熄火顯示端回復第402的無額外外圍光感濾鏡路徑後，採用本頁既有最高亮度`3.20`與對比`1.18`；將金幣重新限制為黃色火焰（程式狀態`orange`）時才啟用；保留煙火既有黃色限定與蝴蝶25.6%同期規則。

原始熄火MP4來源、位元組、影格、幀率、幀序、時長、原生重播、00:00:00時窗、亮度鍵控及幾何均受保護，原始蝴蝶GIF與其他特效亦不在本批次修改範圍。開發頁已重新載入，後續以計算樣式與自然循環讀值驗證上述限定規則。

開發量測已確認熄火在進度0.1917917從原生時間0.010938秒連續播放到0.411449秒，時長仍為1.208334秒且`paused:false`／`readyState:4`。其子層的計算濾鏡為第402路徑加`brightness(3.2) contrast(1.18)`，沒有第403新增的外圍陰影。

黃色測點進度0.2590899中，蝴蝶、金幣與煙火皆可見；煙火原生時間由0.047797秒連續至0.471532秒。非黃色（粉色）測點進度0.2616158中，煙火已正確為`opacity:0`，但金幣容器仍為`opacity:1`。這表示僅透過金幣元件的`enabled`參數不足以保證已存在輸出層立即隱藏；後續只補金幣容器的黃色可見閘門，不改動金幣媒體、Canvas演算法、位置、大小、旋轉、時窗或蝴蝶GIF。

已僅在金幣既有外層補入黃色（`orange`）可見閘門。修改後粉色狀態下，蝴蝶可見時金幣與煙火皆為`opacity:0`；黃色狀態下，進度0.2620676的蝴蝶、金幣與煙火皆為`opacity:1`，煙火原生時間由0.211405秒連續增加至0.631931秒、`paused:false`、`readyState:4`、時長2秒。金幣外層與煙火計算幾何均沒有變更。

第404保存後的首次正式讀值仍為第403舊資源：熄火濾鏡仍有第403外圍陰影且為`brightness(1.12) contrast(1.06)`，粉色金幣仍為`opacity:1`。因此當下正式頁尚未切換，不能將此讀值當作第404結果；待正常資源傳播後才重做正式自然循環驗證。

正式資源傳播後，粉色正式頁確認熄火子層濾鏡已切換為第402路徑加`brightness(3.2) contrast(1.18)`且不含第403外圍陰影；粉色金幣、煙火均為`opacity:0`。切至黃色的正式自然循環中，熄火在進度0.1920238由原生時間0.028325秒連續至0.448763秒，來源與1.208334秒時長不變、`paused:false`、`readyState:4`。黃色蝴蝶時窗進度0.2589725中，蝴蝶、金幣、煙火均為`opacity:1`；煙火原生時間由0.073019秒連續至0.493581秒，仍為2秒、`paused:false`、`readyState:4`，幾何維持left4.5%／top−150%／width90%。
